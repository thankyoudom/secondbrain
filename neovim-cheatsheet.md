# My Neovim Cheatsheet

## Modes
- `Esc` → Normal mode
- `i` → Insert mode
- `v` → Visual mode
- `:` → Command mode

## Save/Quit
- `:w` → Save
- `:q` → Quit
- `:wq` → Save & quit
- `:q!` → Quit without saving

## Movement
- `hjkl` → Left/Down/Up/Right
- `w/b` → Next/Previous word
- `0/$` → Start/End of line
- `gg/G` → First/Last line

## Editing
- `dd` → Delete line
- `yy` → Copy line
- `p` → Paste
- `u` → Undo

## My Custom
- `Space w` → Quick save
- `Space c` → LLM cleanup
- `Space f` → Find files
