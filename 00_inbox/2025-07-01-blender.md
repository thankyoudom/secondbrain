# Blender and Game Modding: Real-World Use Cases

## Games Where Blender is Used for Modding and Content Creation

### Minecraft (Java Edition)
- **What’s possible**: Custom models, mobs, items, environments via `.json` or `.obj` files  
- **How Blender fits**: Used for modeling entities, environments, and textures; exported to Minecraft mod tools  
- **Tools needed**: Blockbench (user-friendly), OptiFine, Forge, MCreator  
- **Community**: Massive modding scene with tutorials and Discord groups  
- **Best for**: Modded assets, custom packs, and map design  

### GTA V (FiveM or Modded)
- **What’s possible**: Custom vehicles, buildings, characters, clothing, weapons  
- **How Blender fits**: Models built in Blender and exported to `.ydr` or `.yft` using tools like GIMS Evo or Sollumz  
- **Tools needed**: OpenIV, CodeWalker, ZModeler3, Blender plugins  
- **Community**: Strong for roleplay servers; artists create car packs or entire cities  

### BeamNG.drive
- **What’s possible**: Custom cars, maps, props, soft-body vehicles  
- **How Blender fits**: Primary tool for building vehicle meshes and skeletons  
- **Tools needed**: Blender JBeam exporter, materials editor  
- **Community**: Physics-focused sandbox; modding is a core part of the culture  

### Skyrim (Special Edition)
- **What’s possible**: Weapons, armor, creatures, animations  
- **How Blender fits**: Uses NIF Tools plugin to export models to `.nif` for Skyrim  
- **Tools needed**: NifSkope, Creation Kit, Blender NIF add-on  
- **Community**: Highly active modding scene as of 2025  

### VRChat
- **What’s possible**: Full-body avatars, custom clothes, environments  
- **How Blender fits**: Standard tool for creating avatars in `.fbx` format  
- **Tools needed**: Unity, VRChat SDK, Blender-to-Unity pipeline  
- **Best for**: Creators who want to build or sell custom avatars and worlds  

### Counter-Strike 2 / CS:GO
- **What’s possible**: Custom weapon skins, maps  
- **How Blender fits**: Used for map modeling or skin visualization  
- **Tools needed**: Valve Hammer Editor, Source 2 SDK  
- **Community**: Competitive players and custom content creators remain active  

### Mount & Blade II: Bannerlord
- **What’s possible**: Custom weapons, helmets, armor, scenes  
- **How Blender fits**: Directly used for model creation  
- **Tools needed**: Modding tools, XML configs, Blender exporter  
- **Community**: Huge modding community; creators build full conversion mods  

### Friday Night Funkin’ (Indie)
- **What’s possible**: Character models, backgrounds, animated sequences  
- **How Blender fits**: Used to create polished cutscenes or redesign characters  
- **Tools needed**: Adobe Animate or mod tools (engine-dependent)  
- **Community**: Strong fan-driven ecosystem; ideal for sharing fan art  

### Terraria (via TModLoader)
- **What’s possible**: Custom mobs, items, bosses  
- **How Blender fits**: Used to visualize 3D sprite concepts before 2D rendering  
- **Tools needed**: TModLoader, JSON configs  
- **Note**: Blender’s role is more creative visualization than direct asset creation
