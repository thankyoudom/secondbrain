# Teeth

## Morning Routine

| Step         | Action                                                      |
|-------------|-------------------------------------------------------------|
|             | Oil pull (10–20 min; continue what you started)             |
|             | Tongue scrape (yes, add this — removes bacteria and debris before brushing) |
|             | Brush with regular toothpaste                               |
|             | Water flosser with plain water (hydrogen peroxide multiple times daily might be too harsh) |

## Evening Routine

| Step         | Action                                                      |
|-------------|-------------------------------------------------------------|
|             | Floss (regular floss is fine; plain water)                  |
|             | Brush with baking soda paste once or twice a week instead of toothpaste (mix baking soda with a little water); use regular toothpaste other nights |
|             | TheraBreath mouthwash                                       |
|             | Whitening strips 1–2x per week (the monthly strength ones you have) |

## Thoughts on Current Setup

- Hydrogen peroxide used in multiple steps might be overkill and could irritate gums over time. The usual recommendation is once daily at most. Consider using it only in mouthwash or occasionally rather than in every step.
- For whitening, stick with your monthly strips rather than daily ones. Use them 1–2x weekly for maintenance instead of switching to weaker daily strips. Daily strips are designed for gentler, everyday use, but since you’re already using stronger monthly strips, spacing them out works well.
- Baking soda is effective for whitening but abrasive. Limit use to a couple times weekly rather than daily.
- Tongue scraping is definitely worth adding — improves freshness and removes the coating that harbors bacteria.
