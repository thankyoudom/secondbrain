# fancy Linux

Ah, I see exactly what you’re asking! That “fancy ASCII Arch Linux logo” you often see is not part of the minimal CLI environment. It’s part of neofetch or the login message on full Arch setups. Here’s the breakdown:

## Minimal Arch Install (CLI)

After booting from the USB and chrooting—or simply logging in post-installation—you’ll typically see a simple prompt:

root@archiso ~#

No ASCII logo by default.

## Fancy ASCII Arch Logo

The fancy ASCII logo you’re referring to is typically generated by tools such as:

- **neofetch** – Shows the Arch logo along with system information. Not installed by default.
- **screenfetch** – Another alternative that displays system info and an ASCII logo.

## How the Logo Appears in Some Setups

On certain Arch-based ISOs (like Manjaro or Arch-based live ISOs), the login prompt is customized via:

- `/etc/issue`  
- A motd (message of the day) script  

Minimal Arch installations leave these blank. You can manually add the logo if desired.

## How to Get the Logo on Your Minimal Install

sudo pacman -S neofetch
neofetch

This will print the Arch ASCII logo along with system information. You can auto-run it at login by adding `neofetch` to your `~/.bash_profile` or `/etc/profile`.
